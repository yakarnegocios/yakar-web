Prioridad autorizada: minería, contratistas y sector industrial. La atención a entidades del Gobierno peruano no se anuncia como segmento comercial. Se conserva el eslogan institucional, diseño, CSS y JavaScript actuales; Perspectiva YAKAR no cambia de edición en este incremento.

Validación local: HTML sin errores en reglas del proyecto; 25 combinaciones de página/ancho (320,360,390,768,1280), controles, reflujo, foco y movimiento reducido; laboratorio de requerimientos sin envíos externos correcto. Revisión visual en celular de portada y nueva guía. Los enlaces de conversión siguen apuntando a #request-start y sus destinos existen. No se añaden dependencias, servicios, scripts externos ni cookies.

La revisión comercial prioriza especificación, condiciones y próximo paso; UX mantiene inicio simple, información progresiva y legibilidad; calidad conserva historial y separación de fechas solicitadas/acordadas; seguridad no introduce promesas de capacidad ni tratamiento nuevo de datos.
