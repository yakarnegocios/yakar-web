# YAKAR

## Abastecimiento estratégico

YAKAR es la marca de Yakar Negocios E.I.R.L.

Este repositorio contiene la primera versión de la presencia web de YAKAR.

### Principios

- CUMPLIR ES PARTE DEL PRODUCTO.
- CERTEZA EN EL ABASTECIMIENTO.
- MÉTODO + VERIFICACIÓN + RESPONSABILIDAD + EVIDENCIA.

### Enfoque inicial

YAKAR desarrolla una propuesta B2B de abastecimiento estratégico para operaciones que necesitan cumplir.

Líneas iniciales:

- Seguridad industrial
- Textil industrial
- Ferretería y suministros
- Equipamiento seleccionable

### Desarrollo

Este proyecto se encuentra en fase de reconstrucción y validación.

La web evolucionará de forma progresiva conforme se validen el modelo comercial, la operación, la oferta, los procesos y la experiencia del cliente.

### Tecnologías

- HTML5
- CSS3
- JavaScript
- GitHub Pages
